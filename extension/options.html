Homepage 新标签页 · 设置 Manifest V3 · 只申请 storage 权限

Chrome 启动时若已经通过新标签页打开了 Homepage，扩展不会重复开标签。

想改设置又不想被立刻跳走时，新建标签页后按住 Shift 即可停留。

使用提示

  • 新建标签页会被自动替换为 Homepage；点击扩展图标也能随时打开。
  • Chrome「设置 → 启动时」选「打开新标签页」即可天然生效；选「继续上次会话」时由扩展在启动后自动补开一个 Homepage 标签。
  • 如果页面报 Host validation failed，把这里的域名（含端口）加进服务端的 HOMEPAGE_ALLOWED_HOSTS，并确认 NEXTAUTH_URL 与访问地址一致。
  • 本扩展与其它新标签页扩展（WeTab、Infinity 等）会冲突，请只启用一个。
  • 采用整页跳转而不是 iframe 内嵌：自托管站点常有 X-Frame-Options / CSP 限制，内嵌会被拦、登录 Cookie 也容易失效。
  • 配置存于 chrome.storage.local，不申请 tabs / 网络 / 遥测权限，不含任何预置的私有地址。
